Privacy policy — H3 Studio Backup

H3 Studio Backup is a personal tool used only by its owner.

  • It accesses only the owner's own Google Drive, and only to save and restore the owner's own H3 Studio files (in a folder called "H3 Studio") and a settings file the owner keeps there.
  • It does not collect, sell or share any data with anyone. Nothing is sent to the developer or to any third party.
  • Google sign-in details stay on the owner's own computers. The owner can remove access at any time at myaccount.google.com → Security → Third-party connections.

Last updated: October 2026.
